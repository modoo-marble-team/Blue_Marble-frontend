# README Screenshot Assets

루트 `README.md`에 직접 들어가는 서비스 스크린샷을 이 폴더에 저장한다.

## Current Files

- `lobby-overview.png`

- `gameplay.png`
- `my-page.png`

## Rules

- 외부 hotlink 대신 저장소 내부 파일을 사용한다.
- 파일명은 화면 목적이 바로 보이게 짓는다.
- 가능한 한 동일한 해상도와 비율로 정리한다.
- 너무 많은 이미지를 넣기보다 핵심 사용자 흐름 4~6장으로 압축한다.
- 현재 루트 `README.md`에는 위 5장을 모두 inline으로 사용한다.
