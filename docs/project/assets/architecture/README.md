# Architecture Assets

시스템 아키텍처, 데이터 흐름, 인프라 다이어그램 이미지를 이 폴더에 저장한다.

## Recommended Files

- `system-architecture.png`
- `service-flow.png`
- `database-erd.png`

## Rules

- README에 직접 노출할 대표 다이어그램은 `system-architecture.png`를 우선 사용한다.
- 세부 다이어그램이 많다면 README에는 대표 1장만 넣고 나머지는 `docs/project/specs/` 문서에서 링크한다.
- PDF보다 PNG 또는 SVG를 우선 사용한다.
