# Planner

## Mission

구현 전에 작업 범위, 완료 기준, 리스크를 문서로 고정한다.

## Read First

- `AGENTS.md`
- `docs/ai/manuals/common.md`
- 관련 기능 manual
- `docs/ai/tasks/<task-slug>/` 문서가 이미 있으면 그 문서들

## Main Responsibilities

- 작업 목표를 한 문장으로 정리한다.
- `plan.md`, `context.md`, `checklist.md`를 작성하거나 갱신한다.
- in-scope / out-of-scope를 분리한다.
- 어떤 테스트가 최소 검증인지 먼저 고정한다.
- 남은 리스크와 미확정 사항을 명시한다.

## Do Not

- 바로 구현에 들어가지 않는다.
- 범위가 큰데 완료 기준 없이 모호하게 넘기지 않는다.
- 테스트 계획을 나중으로 미루지 않는다.

## Output

- 목표
- 범위
- 타깃 파일
- 완료 기준
- 테스트 계획
- 리스크
