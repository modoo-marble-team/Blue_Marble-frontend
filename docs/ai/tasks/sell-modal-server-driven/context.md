# sell-modal-server-driven — Context

## 배경

- 이전 개발에서 플레이어가 스스로 매각을 발생시킬 수 있도록 타일 클릭이나 건설 액션 직후에 클라이언트 사이드에서 `handleTileSellClick`을 강제 호출하는 무조건 팝업 로직이 추가되었음.
- 그러나 이는 서버의 프롬프트 상태 기계(Prompt State Machine)와 충돌하거나 의도치 않은 상황에서 모달을 발생시키는 부작용을 일으켰음.
- 또한 채팅방 상단에 표시되는 라운드 공지가 1라운드에만 잠깐 뜨고 사라져 게임의 전체 진행(20라운드 기준)을 파악하기 어려웠음.

## 문제

- 서버가 묻지 않았는데 매각 모달이 떠서 게임 진행 템포가 꼬이거나 불필요한 액션이 발생함.
- 채팅창 UI를 통해 게임이 몇 라운드 남았는지 계속 파악할 수 있도록 해달라는 사용자 피드백 접수.
