# Context: Island Modal Text Fix

## 목적

- `IslandModal.tsx`에서 무인도 구금 시 나타나는 텍스트를 개선합니다.
- 단순 안내 메시지 대신 구금된 상태와 남은 턴 수를 명확하게 항상 표시하도록 변경합니다.

## 변경 내용

- 기존: `restTurns`가 있을 때만 턴 수 표시, 없으면 "당신은 무인도에 갇혔습니다."만 표시
- 변경: 무조건 "당신은 무인도에 갇혔습니다. ${restTurns}턴 동안 쉽니다." 형식으로 표시
- (참고: `restTurns`가 null이나 0인 경우에 대한 기본값 처리가 필요할 수 있음)
