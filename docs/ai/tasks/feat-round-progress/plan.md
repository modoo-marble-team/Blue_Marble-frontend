# `feat/round-progress` 작업 계획

## 배경

직전 작업에서 라운드 정보를 서버 `turn`과 연동시키고 상시 노출하는 형태로 UI 변경을 진행했으나, 다시 이전처럼 "게임 시작! 순서를 정했습니다." 텍스트만 최초에 보여주다 사라지게 하고, 화면에 찍히던 턴 관련 문구(`(1/20 턴)`, `Turn 1 / 20` 등)를 전부 제거해달라는 피드백이 있었습니다.

## 목표

1. **채팅방 상단 알림 원상복구**: `GamePage.tsx`에서 `({round ?? 1}/20 턴)` 문구를 제거하고, 1턴(라운드) 이후에는 `notice`가 `undefined`가 되어 자연스레 사라지도록 복구합니다.
2. **보드판 내 턴 표출 영역 제거**: `GameBoard.tsx` 우상단에 추가했던 `Turn {round ?? 1} / 20` 표출 엘리먼트를 아예 삭제합니다.
3. **라운드 툴팁/상태 메시지 턴/라운드 문구 제거**: 필요시 알림 메시지 뒤에 붙던 ` · 1/20턴` 형식의 상태 라벨(`roundLabel`)도 제외할지 확인합니다 (사용자 요청 "화면상에서 보이는거 전부 빼줘"에 부합).
