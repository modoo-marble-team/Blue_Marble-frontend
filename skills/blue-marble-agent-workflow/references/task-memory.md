# Task Memory

Use `docs/ai/tasks/<task-slug>/` for any non-trivial task.

## plan.md

Record:

- goal
- in-scope / out-of-scope
- target files
- completion criteria
- test plan

## context.md

Record:

- current behavior
- related files and docs
- constraints
- chosen approach
- open risks

## checklist.md

Track:

- implementation steps
- validation steps
- review steps

Re-open these files in a new session before implementation or review.
